# Transformation in ETL – Assignment

## About the Assignment

This repository contains my assignment on **Transformation in ETL**.

The assignment covers important concepts related to data transformation and data cleaning in the ETL process. It includes topics such as normalization, standardization, missing values, one-hot encoding, data integration, data mapping, and handling outliers.

## Assignment Topics

The following questions are covered in this assignment:

1. Data Transformation in ETL and its importance
2. Common activities involved in Data Cleaning
3. Difference between Normalization and Standardization
4. Techniques for handling missing values
5. Standardizing inconsistent Gender values
6. One-Hot Encoding
7. Difference between Data Integration and Data Mapping
8. Z-score Standardization and Min-Max Scaling with outliers
